# Decision: AXR v0.3.0 result fidelity

Date: 2026-10-23

Status: Accepted for specification implementation at the user's request.

## Intent

Represent production result shapes that AXR v0.2.0 cannot express: entrants
without a finishing position, disqualifications with retained numeric attempts
and printed-total provenance, explicit indexed competition groups, and
test-and-tune events. Keep the format application-neutral.

## Decision

Publish a new v0.3.0 working draft in this repository. Preserve v0.1.0 and
v0.2.0 byte-for-byte. Point the repository's latest mirror at v0.3.0.

- Keep position required, but allow null for an unplaced entrant.
- Add DQ as a totalTime alias for DSQ and allow DQ/DSQ in bestTime.
- Add nullable numeric sourcePrintedTotal for disqualified results. It is
  provenance, never a scored time. Preserve all run arrays.
- A final DQ/DSQ requires null position and cannot award a trophy. Status-valued
  bestTime and non-null sourcePrintedTotal require a final DQ/DSQ.
- Add event.isPaxed and event.paxClasses for explicit indexed scoring. Class
  references use exact shortName, falling back to name when shortName is absent
  or null. Document reference resolution as a semantic consumer check.
- Add TestAndTune to event.type. Ranking eligibility remains consumer policy.

Do not introduce repair commands, internal IDs, or application audit controls
into the exchange format. Existing car, hometown, sponsor, division, PAX-note,
and run fields already cover those source facts.

## Compatibility and release boundary

This is a spec-repository change, not a production deployment. As checked on
2026-10-23, AutocrossRank's importer accepts only 0.1.0 and 0.2.0. Hosting and
importer support for 0.3.0 require a separate integration. Do not describe the
new canonical URL as already deployed.

## Validation

Validate all versions' examples, test new valid and invalid result shapes,
check version isolation and exact latest-mirror equality, and confirm old
versioned schemas are unchanged.

## Outcomes

Implemented the v0.3.0 schema, latest mirror, seven examples, migration and
producer guidance, and CI validation. All 15 contract tests and 14 examples
across three versions pass. The v0.1.0/v0.2.0 schema files are unchanged.
Cross-class PAX reference resolution is explicitly documented as a semantic
check outside portable JSON Schema validation. No application deployment or
production data change is included.
